# Doomscrolling in the Deep

A Chrome extension that interrupts short-form video feeds with a gentle reminder: **McDonald's is hiring.**

## Run it locally

```bash
npm install
npm run build
```

Then open `chrome://extensions`, turn on **Developer mode**, choose **Load unpacked**, and select this project's `dist` folder.

Open YouTube Shorts, TikTok, or Instagram Reels. Click **Give me 30 more seconds** to hide the card temporarily, or **View applications** to open McDonald's Careers.
