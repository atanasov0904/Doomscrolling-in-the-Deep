# Doomscrolling in the Deep

A Chrome extension that interrupts YouTube Shorts with a gentle reminder: **McDonald's is hiring.**

## Run it locally

```bash
npm install
npm run build
```

Then open `chrome://extensions`, turn on **Developer mode**, choose **Load unpacked**, and select this project's `dist` folder.

Open any YouTube Shorts URL. Click **Give me 5 more minutes** to hide the card temporarily, or **View applications** to open McDonald's Careers.
