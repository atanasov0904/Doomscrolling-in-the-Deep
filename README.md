# Doomscrolling in the Deep

A chrome-based extension that reminds you that doomscrolling is not the optimal life with:
**McDonald's is hiring.**

## For now needs to be run locally, not ready for deployment

```bash
npm install
npm run build
```

Then open `chrome://extensions`, turn on **Developer mode**, choose **Load unpacked**, and select this project's `dist` folder.

Open YouTube Shorts, TikTok, or Instagram Reels. Click **Just a little break tho!** to hide the card temporarily, or **View future oppurtunities** to open McDonald's Careers.Recently added a new button **Get into the zone now.** that sends you to a linkedin job finder *default* and soon will be implemented to let you assign a website to your liking.
